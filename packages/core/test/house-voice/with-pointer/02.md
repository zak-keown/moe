# @bubstack/moe-relay

Forward lifecycle events between coding-agent sessions. A controller session
learns that a worker finished without polling it.

**Status:** imported, complete. 214 tests passing across 19 suites; 8 more in 2
suites skip themselves without a local `redis`. Nothing was left out. The event
schema is at `v2` and `v1` is still accepted, so one removal remains open — see
[The event schema](#the-event-schema).

Ships as the **`moe-relay`** plugin. `@bubstack/moe-mint` generates it into
`/plugins/moe-relay` from `packages/relay/mint/moe-relay.yaml`. Never hand-edit
the generated manifest. The binary is `moe-relay`.

## Transports

The default transport is a local unix socket, which covers every run on one
host. An optional redis transport carries the same events across hosts. Choose
redis only when sessions span machines; the socket needs no daemon, and the 8
skipped tests are the redis suites declining to run without one.

## The event schema

Events are versioned. `v2` is current. The relay still accepts `v1`, and will
keep accepting it until no worker emits it; support drops then, not before.

## `relay → tab` is REFUTED

We expected a dependency edge from `relay` to `tab`, on the assumption that the
relay would attribute cost per session. It does not. The relay never reads token
usage at all, and `tab` is not a dependency. The belief was wrong, and this
paragraph exists so the next reader does not re-derive it.
