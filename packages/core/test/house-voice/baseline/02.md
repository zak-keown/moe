# @bubstack/moe-relay

`@bubstack/moe-relay` forwards lifecycle events between coding-agent sessions. A
controller session learns that a worker session finished the moment the relay
delivers the event, so the controller never polls the worker. The package ships
one binary, `moe-relay`.

## Transport

The relay carries events over a local unix socket. Runs that span more than one
host can use the optional redis transport instead.

## Event schema

Events are versioned, and the current version is `v2`. The relay still accepts
`v1` events. We will drop `v1` once no worker emits it.

## The relay ignores cost

The relay never reads token usage. Going into the import we expected
`relay → tab` to be a dependency edge, because we assumed the relay would
attribute cost per session. That assumption was wrong: `tab` is not a
dependency.

## Plugin build

`@bubstack/moe-mint` generates this package into `/plugins/moe-relay` from
`packages/relay/mint/moe-relay.yaml`. Edit that yaml. Never hand-edit the
generated manifest.

## Tests

214 tests pass across 19 suites. Two further suites, 8 tests in all, skip
themselves when no local `redis` is running; start redis to run them.
