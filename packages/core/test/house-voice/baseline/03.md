# @bubstack/moe-relay

Forwards lifecycle events between coding-agent sessions, so a controller session
learns that a worker session finished without polling it. The package installs
one bin, `moe-relay`.

## Transport

Events travel over a local unix socket. Runs that span more than one host can
use the optional redis transport instead.

## Event schema

The schema is versioned and currently sits at `v2`. The relay still accepts `v1`
events; that support ends once no worker emits them.

## Cost attribution

The relay never reads token usage, and it attributes no cost.

Going into the import we expected `relay → tab` to be a dependency edge, on the
assumption that the relay would attribute cost per session. It does not, and
`tab` is not a dependency. We were wrong about that.

## Plugin generation

This package ships as a plugin. `@bubstack/moe-mint` generates it into
`/plugins/moe-relay` from `packages/relay/mint/moe-relay.yaml`. Change the
plugin by editing that yaml. Never hand-edit the generated manifest.

## Tests

214 tests pass across 19 suites. Two further suites hold 8 tests that skip
themselves when no local `redis` is running.
