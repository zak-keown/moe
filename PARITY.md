# Imported-data parity

## Unicode CaseFolding 16.0.0

`packages/mint/src/artifact/unicode-casefold.ts` is generated from Unicode
Character Database `CaseFolding-16.0.0.txt` (2024-04-30), using all and only
the `C` and `F` mappings; Turkic-only `T` mappings are excluded. The source is
`https://www.unicode.org/Public/16.0.0/ucd/CaseFolding.txt`. The offline test
fixture is the unmodified source file and parses independently of production
data. `NOTICE` retains Unicode License V3.
