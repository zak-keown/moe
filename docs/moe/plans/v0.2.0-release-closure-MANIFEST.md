# Moe v0.2.0 Release Closure Plan Set

This set replaces the obsolete `0.1.x` release plans for the coordinated
`v0.2.0` release. It runs in order because every later plan consumes exact
artifact and release contracts from its predecessor.

```yaml
plan_set_id: v0.2.0-release-closure
depends_on_plan_sets: []
plans:
  - id: release-baseline
    plan: docs/moe/plans/2026-09-04-v0.2.0-release-01-baseline.md
    depends_on: []
    status: pending
  - id: release-orchestration
    plan: docs/moe/plans/2026-09-04-v0.2.0-release-02-orchestration.md
    depends_on: [release-baseline]
    status: pending
  - id: release-qualification
    plan: docs/moe/plans/2026-09-04-v0.2.0-release-03-qualification.md
    depends_on: [release-orchestration]
    status: pending
  - id: candidate-and-promotion
    plan: docs/moe/plans/2026-09-04-v0.2.0-release-04-candidate-promotion.md
    depends_on: [release-qualification]
    status: pending
```

The final plan includes protected-environment actions. No executor may publish,
create a release, or move an npm tag before the user approves that action.
