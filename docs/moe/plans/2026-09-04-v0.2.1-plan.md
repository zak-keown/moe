# v0.2.1 release plan — cleanup, reproducibility, doc-truthing

**Goal:** ship a patch that fixes what is broken or untrue today. No new
capability. Tracks: verify 0.2.0's packaging fix landed; the reproducibility
fixes (umask #4, the merged EPIPE #5, main's red render-graphs) and the
low-severity backlog follow-ups; and a dead-code + doc-truthing sweep from the
promise-hunt audit.

> **Correction (this session):** an earlier draft made packaging the "spine" of
> 0.2.1. On verification, packaging is solved by 0.2.0's release orchestration
> (see Track 1); 0.2.1's real weight is the cleanup + reproducibility tracks.

**Baseline:** `main` @ `64304930`; assumes `v0.2.0` has shipped (six public
packages at `0.2.0`). Authored 2026-09-04. See
[roadmap](./2026-09-04-release-roadmap-0.2.1-0.3.0.md) for the split rule and
inputs.

**Conventions:** every SKILL.md / hook / manifest change is mirrored into
`/plugins/` by `pnpm mint` — never hand-edit `/plugins/`. Gate each change with
`pnpm check` and `pnpm mint:check`; packaging changes also need
`pnpm provenance`.

## Track 1 — Packaging: verify 0.2.0's fix landed (NOT a 0.2.1 build)

### P — Packaging is solved by design; 0.2.0 owns the wiring  ·  size S (verify only)  ·  CORRECTED

An earlier read this session flagged the install as broken and made packaging
the 0.2.1 headline. That was an over-call: it `npm pack`-ed the raw
`packages/<pkg>` workspace (the old 0.1.x publish path), not what the release
orchestration publishes. Corrected finding, verified on `main` @ `64304930`:

- `release/candidate.ts` `prepareCandidate` packs `artifact.artifactRoot`, which
  `artifact/check.ts` sets to `plugins/<id>` — the **complete** generated tree
  (`.claude-plugin/plugin.json`, LICENSE, NOTICE, `dist`, all 8 harness dirs;
  `license-payload.ts` writes LICENSE/NOTICE into that root).
- `publish.yml` already runs `mint release candidate --execute` on a `v*-*` tag.
- But `release candidate/promote/certify-claude --execute` all throw
  `*_EXECUTE_NOT_WIRED` on main — so a real 0.2.0 tag fails loudly there until
  wired. Never a silent broken ship.

So this is **0.2.0's last mile, not a 0.2.1 feature.** Tracked as
`BL-d932811282`. The already-published 0.1.x tarballs *are* incomplete (old
path), so 0.1.x installs stay broken until 0.2.0 republishes complete trees.

**0.2.1's only job here — verify, don't build:** confirm 0.2.0 wired the three
`--execute` paths and that a promoted tarball contains
`.claude-plugin/plugin.json`, the reachable SessionStart bootstrap, LICENSE and
NOTICE (`artifact/check.ts` already asserts file presence). The one true
residual — an end-to-end "after install, the bootstrap fires" test for the
non-memory plugins — is a 0.3.0 item under robust e2e testing (`BL-3ce1956bb4`),
not a patch. If 0.2.0 slips its wiring, this is the item that escalates.

## Track 2 — In-flight fixes + backlog v1.5 follow-ups

### B — main CI is red on render-graphs (`BL-40d3f00a09`)  ·  size M
`origin/main`'s `ci` workflow is failing (at `64304930` and `ffbf1bf6`):
`packages/core/test/render-graphs.test.ts` → `ENOENT ... fixture_skill_harmless
_combined.svg`. The combined SVG never renders in CI (likely a missing/misbehaving
graphviz `dot`, or a real regression), and it isn't gated behind a runtime check
so it fails the whole `test` job. A red `main` blocks a clean 0.2.x cut.
**Acceptance:** reproduce locally; then either install the dependency in `ci.yml`,
make the test self-skip when the renderer is absent (matching the tmux/Chrome
pattern), or fix the combine step. Decide skip-vs-fix.

### G4 — Artifact generation is umask-dependent (issue #4)  ·  size M
`mint:check` is non-reproducible across hosts and a committed manifest can't be
verified after a clone with a different umask. Confirmed present at `6430493`.
Fix: derive recorded mode from the executable bit alone —
`(mode & 0o111) ? 0o755 : 0o644` — at the staging site and in `exactMode()`, and
`chmod` explicitly after every create; keep rejecting setuid/setgid/sticky.
Sites in the issue: `assemble.ts`, `manifest.ts`, `license-payload.ts`,
`projections.ts`, `artifact-manifest.ts` (`exactMode`), and the
`pack-artifact.test.ts` fixture. Reporter has a verified fork fix and offered a
PR. **Acceptance:** `pnpm mint --force` byte-identical under `umask` 022/000/077.

### G5 — jig-worktree-guard EPIPEs its caller (issue #5 / PR #6)  ·  size S
PR #6 is mergeable, one file (`packages/core/hooks/jig-worktree-guard`, +7/−1):
drain stdin before the `MOE_JIG_RAW_WORKTREE` early exit, matching
`jig-review-format-guard`. Review + merge; re-mint so the fix reaches
`/plugins/`. **Acceptance:** escape hatch exits 0 with a 200 KB event; block
path still exits 2; `packages/jig/test/hooks.test.ts` green.

### BL-2064cbd0a5 — `decline` should strip a stale `## Resume` block  ·  size S
`writeDisposition` in `packages/jig/src/backlog.ts` appends under
`## Disposition` but leaves a prior `## Resume` block, so a `defer → decline`

### BL-5897265d07 — `fixing-a-code-review` SKILL.md → `BL-<hex>` id shape  ·  size S
`packages/core/skills/fixing-a-code-review/SKILL.md` still says "Record the
